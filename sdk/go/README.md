# AgentFileOps Go SDK

The Go SDK provides a typed client for AgentFileOps services and may share models with the `agent-file-opsd` daemon track.

Goals:

- small dependency footprint;
- stable protocol types;
- streaming transfer support;
- normalized errors/results;
- shared conformance fixtures.

The SDK is distinct from the daemon. Neither may redefine protocol semantics.
