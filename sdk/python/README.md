# AgentFileOps Python SDK

Python is a first-class AgentFileOps SDK and automation surface, not the identity of the product.

Planned responsibilities:

- typed AgentFileOps client;
- scripting and notebook workflows;
- automation integrations;
- migration helpers from `hostinger-file-bridge`;
- conformance fixture runner where useful.

The SDK must not invent protocol behavior. It should consume generated/adapted protocol types and normalize results identically to other AgentFileOps surfaces.
