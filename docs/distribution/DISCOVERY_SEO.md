# Discovery & SEO Strategy

## Target Vocabulary

AgentFileOps targets the keywords and phrases people use when searching for remote file operations for AI agents:

- AI agents, MCP, Model Context Protocol
- Remote filesystem, SSH, SFTP, file transfer
- Remote file operations, remote server
- Server file management, sync, deployment
- DevOps, automation, artifact publishing

## Discovery Metadata

Brand stays memorable (AgentFileOps) while repository descriptions, package metadata, MCP metadata, skills, and release pages carry descriptive search language.

## Primary Surfaces

- GitHub repository description and topics
- NPM package keywords and metadata
- MCP package discovery
- skills.sh catalog entries
- Distribution documentation
