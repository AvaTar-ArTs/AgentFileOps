**Tagline:** \"Give agents files, not a shell\"\n- **Category:** Remote File Operations for AI Agents\n- **Tone:** Technical, trustworthy, precise, empowering\n\n### Color Palette\n\n#### Primary hierarchical, flow top-to-bottom\n\n```\nAgent / MCP Client / Human Operator\n         ↓ (connection)\nAgentFileOps Protocol Layer\n         ↓ (semantic operations)\nRisk Classification Engine\n         ↓ (safety check)\nConnection Resolution\n         ↓ (path/backend selection)\nSSH/SFTP Transport\n         ↓ (execution)\nRemote Server (VPS, NAS, Shared Hosting)\n```\n\n**Colors by Layer:**\n- Agents: #0F1E37 (Navy) boxes\n- Protocol: #00C8FF (Cyan) borders\n- Risk: #FFB400 (Amber) for medium-risk highlighting\n- Transport: #108040 (Green) for approved operations\n- Server: #6C757D (Gray) external system\n\n### Risk Level Chart\n**Theme:** Vertical scale, color-coded severity\n\n```\nLevel 0 (Safe Read)           ← #00C8FF (Cyan)\nLevel 1 (Low Risk Create)     ← #108040 (Green)\nLevel 2 (Medium Risk Modify)  ← #FFB400 (Amber)\nLevel 3 (High Risk Delete)    ← #FF8C42 (Orange)\nLevel 4 (Critical Bulk)       ← #DC3545 (Red)\n```\n\nEach level shows:\n- Risk level indicator\n- Example operations\n- Approval requirements\n- Safety constraints\n\n### Data Flow Diagram\n**Theme:** Connected nodes, bidirectional arrows\n\n```\n[Descriptor] → [Validator] → [Executor] → [Result]\n                    ↑                        ↓\n                    └────── [Audit Trail] ──┘\n```\n\n**Colors:**\n- Input nodes: #0F1E37 (Navy)\n- Processing nodes: #00C8FF (Cyan)\n- Output nodes: #108040 (Green)\n- Error paths: #DC3545 (Red)\n\n### Icons\n\n#### Operation Icons (24×24px, stroke-based)\n```\nList (folder icon):       Stacked horizontal lines\nRead (document icon):     Document with eye overlay\nWrite (pencil icon):      Pencil or pen\nDelete (trash icon):      Trash can\nCopy (duplicate icon):    Overlapping squares\nSync (arrows icon):       Circular arrows (both directions)\nArchive (box icon):       Storage box\nConnect (link icon):      Chain link or plug\nLock (security):          Padlock\nCheck (approval):         Checkmark circle\n```\n\n**Icon Style:**\n- Stroke width: 2px\n- Fill: None (stroke-based)\n- Corner radius: 2px for modern look\n- Colors: Match operation context (risk level)\n\n---\n\n## Layout Patterns\n\n### Dashboard
