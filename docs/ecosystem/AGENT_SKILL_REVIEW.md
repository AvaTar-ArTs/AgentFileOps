# Agent Skill Review

## Purpose

Documents the agent ecosystem roles that review and verify AgentFileOps development.

## Core Agents

- **AgentFileOps Orchestrator** (from superAgents): Orchestration, verification, policy boundaries, catalog locking
- **AgentFileOps Protocol Architect** (from agent-skills): Protocol design, schema, cross-platform compatibility
- **AgentFileOps Security Reviewer** (from agent-skills): Safety-first enforcement, risk classification, audit design
- **AgentFileOps Conformance Verifier** (from agent-skills): Vertical slice validation, black-box testing

## Ecosystem Sources

- `AvaTar-ArTs/superAgents` - Orchestration and verification roles
- `AvaTar-ArTs/superSkills` - Curated skill contracts and catalog boundaries
- `AvaTar-ArTs/agent-skills` - Specialist skills: architecture, security, testing, DevOps, code review
